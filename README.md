# The Sunken Covenant

A naval strategy game for the browser, built with three.js. See `docs/PLAN.md` for the design and roadmap.

Phase 1 is playable: one captain against the computer.

```bash
npm install
npm run dev     # play at the printed local address
npm test        # game rules and bot tests
npm run build
```

Controls: click to act, `F` / `S` / `T` to pick Fire, Sail or Turn, `Space` to end the turn, `R` to rotate a lifted ship during deployment.
